# 거제 옥포 설계표 수치 확인

설계표(문제와 대상 · 페르소나 차별화)에 적은 수치가 실제 데이터와 맞는지 확인한 기록이다. 확인일은 2026-11-27이다.
표 파일은 `data/processed/okpo/` 에 있고, 만드는 방법은 `python3 -I tools/build_okpo_inputs.py` 이다.

## 맞는 것

| 설계표 문구 | 데이터 | 근거 파일 |
|---|---|---|
| 동남권 공실률 1위 · 중대형 38.0% | 거제옥포 중대형 **37.99%** (2026년 3분기). 부산·울산·경남 46개 상권 중 1위이고, 2위는 진주중앙시장 29.56% | `data/raw/reb/vacancy_dongnam.csv`, `okpo/08_vacancy_okpo.csv` |
| 전체 32.8% | 거제옥포 일반 상가 **32.77%**. 46개 상권 중 1위 | 〃 |
| (참고) 같은 시 비교 | 거제고현 중대형 15.70%로, 옥포가 2배 이상 높다 | `data/raw/reb/vacancy_dongnam.csv` |
| (참고) 악화 추세 | 옥포 중대형 2024년 3분기 29.51% → 2026년 3분기 37.99% | `okpo/08_vacancy_okpo.csv` |
| 외국인 근로자 급증 | 옥포1·2동 등록 외국인 2018년 1,572명 → 2026년 10월 2,101명 (**+34%**) | 2018년은 원자료 `외국인 국적별 등록현황`, 2026년은 `okpo/03_foreign_by_visa.csv` |
| 외국인 근로자 집단의 구성 | 일반기능인력 E-7-3 356명, 제조업 E-9 242명, 선박설비 D-9-3 200명, 결혼이민 F-6 206명 | `okpo/03_foreign_by_visa.csv` |
| 주말 관광객 | 거제 외지인 방문자: 월~목 일평균 5.0~5.4만 명, 금 6.3만 명, 토 8.6만 명, 일 8.1만 명 | `okpo/10_visitors_weekday_geoje.csv` |

참고: 외국인 방문자는 요일과 관계없이 일평균 약 6천 명으로 일정하다. 관광객보다 상주 근로자에 가깝다.
2018년 옥포 외국인은 미국·영국·노르웨이 등 조선 관련 서구권 인력이 많았다. 2026년에는 E-7·E-9 체류자격(베트남·인도네시아 등)이 중심이다.

## 근거가 부족한 것

| 설계표 문구 | 상태 |
|---|---|
| 조선소 초호황 | 공개 자료가 2022년까지라 반등을 보여 주지 못한다. 한화오션 직영 인원은 2015년 13,540명에서 2022년 8,303명으로 줄었다. 최근 수주·고용 자료(회사 공시, 거제시 통계)가 더 필요하다. |
| 교대 패턴 통근 시각 (출근 07~08시 · 점심 12시 · 퇴근 17~18시) | 공개 자료가 없다. 가정값으로 두고 가정이라고 표시한다. |
| 본국 송금 · 식문화 선호 · 가성비 예산 한도 | 거제 단위 자료가 없다. 예산의 기준값은 카드매출 건당 금액(`okpo/05`)을 쓴다. 예: 20대 15,271원. |
| 옥포만의 관광객 수 | 방문자 수는 시 단위뿐이다. 옥포 카드매출에서 외지인 비중은 건수 기준 8.7%이다. |
