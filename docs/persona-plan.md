# 옥포 가상 시민 1만 명 — 페르소나 작업 계획

작성 2026-11-27. 다음 세션은 이 문서의 **7. 다음에 할 일**부터 이어서 진행합니다.

> 페르소나는 가상 인물입니다. 결과는 실제 방문·매출 예측이 아니라 조건끼리 비교하기 위한 시나리오입니다.

## 1. 범위

- **대상 구역**: 거제시 「옥포로·성안로 ~ 옥포국제시장 일대」(구 옥포 외국인거리·빛의 거리). 부동산원 공실률의 '거제옥포' 상권.
- **우리 담당**: 페르소나 생성만. 3D 거리·건물·가게는 다른 파트가 만들고, 우리는 그 파트가 읽어 갈 페르소나 파일을 넘긴다.
- **1만 명의 정의**: 하루 동안 옥포 구역에 오는 사람(주민 + 조선소 노동자 + 외국인 + 관광객). 가능한 한 **실제 유동인구 규모·구성과 비슷하게** 만든다.

## 3. 페르소나 필드 (초안)

가정으로 만든 값에는 이름 끝에 `_synthetic` 을 붙여, 근거 있는 값과 구분합니다.

| 필드 | 예 | 근거 |
|---|---|---|
| `persona_id`, `synthetic` | `OP-P00001`, true | |
| `segment` | 주민 / 출퇴근·업무 유입 / 외국인 노동자 / 관광객 | 생활인구, 체류자격별 외국인, 관광 데이터랩 |
| `age`, `age_band`, `sex` | 34, 30대, 남성 | 면동별 연령분포, 성연령별 생활인구 |
| `home_area` | 옥포1동 / 거제 다른 동 / 통영 / 부산 / 해외(국적) | 보고서 유입 시도·시군, 카드매출 유입광역시도 |
| `nationality` | 한국 / 베트남 / 우즈베키스탄 … | 외국인주민현황, 체류자격별 |
| `occupation_synthetic` | 조선소 협력사 / 자영업 / 가사·돌봄 … | 산업별 종사자, 양대 조선소 종사자 |
| `visit_purpose_synthetic`, `party_size_synthetic`, `transport_synthetic` | 퇴근 후 식사, 2, 버스 | 가정(+ 국민여행조사로 관광객 보정) |
| `weekday_/weekend_arrival_hour·minute` | 18:40 | **근거 없음(7절)** |
| `weekday_/weekend_dwell_minutes_synthetic` | 90 | 가정 |
| `visit_budget_krw_synthetic`, 업종별 1회 상한 | 35,000 | 카드매출 건당 금액(금액 ÷ 건수) |
| `price_sensitivity_synthetic`, `max_wait_minutes_synthetic` | 높음, 10 | 가정 |
| `category_preference_weights_synthetic` | 음식 0.45, 유통 0.2 … | 카드매출 옥포1·2동 연령·성별 × 업종 비중 |
| `decision_criteria_weights_synthetic` | 가격·맛·접근성·대기 … | 가정 |
| `weekday_/weekend_expansion_weight` | 페르소나 1명 = 실제 몇 명 | 생활인구 ÷ 1만 |
| `description_synthetic` | 한 줄 설명 | 위 값으로 생성 |

## 4. 확인한 근거 수치

**생활인구** (거제시 데이터포털 「빅데이터기반 지역현황 분석(2026년 10월)」, SKT. `data/raw/geoje/floating_population/`)

| | 주민등록 | 생활인구(면동 평균 체류 인원) | 배율 |
|---|---|---|---|
| 옥포1동 | 7,158 | 29,067 | 4.06 |
| 옥포2동 | 23,198 | 38,800 | 1.67 |
| 거제시 | 228,483 | 일평균 281,667 | 1.23 |

- 옥포1동은 시내 동 가운데 주민 대비 생활인구 배율이 가장 높다(상권·외부 유입형).
- 거제시 성연령별 생활인구와 주민등록의 차이가 가장 큰 것은 30·40대 남성이다(40대 남성 생활인구 32,391 대 주민 약 23,000).
- 경남 안 유입의 약 52.2%가 통영이고 남성이 약 70%다. 광역 유입의 남성 비율은 67.9%다. 조선소·산업 출퇴근 성격으로 보인다.
- 2021년 9월 보고서(KT)의 옥포1동 월 총유동인구는 490,457명이다. 통신사와 정의가 달라 직접 비교하지 않는다.

**공실률** (부동산원, 거제옥포, 2026년 3분기): 일반 32.77%, 일반 1층 14.06%.

**관광 데이터랩** (거제시 일별, 예: 2025-11-27 목요일): 현지인 254,531 · 외지인 50,572 · 외국인 4,964.

## 5. 1만 명을 만드는 방법 (계획)

1. **구성 비율**
   - 주민과 외부 유입은 옥포1동 기준으로 약 25 : 75(7,158 ÷ 29,067)로 나눈다. 옥포2동을 얼마나 섞을지는 구역 경계를 보고 정한다.
   - 외부 유입은 다시 거제 다른 동 / 경남 인근(통영·진해) / 광역 / 외국인으로 나눈다. 근거는 보고서 유입 비율, 카드매출 유입광역시도, 관광 데이터랩이다.
   - 외국인은 체류자격별 외국인의 옥포1·2동 열로 국적과 비자 유형을 배분한다.
2. **나이·성별**: 주민은 면동별 연령분포에서, 유입은 성연령별 (생활인구 − 주민등록) 차이에서 가져온다. 배분은 최대잔여법으로 정수 인원을 맞춘다.
3. **소비 선호·예산**: 카드매출에서 `행정동 ∈ {옥포1동, 옥포2동}` 만 뽑아 연령 × 성별 × 업종대·중분류의 금액 비중과 건당 금액을 구한다. `연령대 = 기업` 은 뺀다.
4. **확대 가중치**: 구역 하루 실제 방문자 추정치 ÷ 10,000. 추정치를 어떻게 잡았는지 `generation_rules.json` 에 적는다.
5. **검증**: 생성 결과의 연령·성별·구분 비율이 목표와 맞는지, 업종별 지출 비중이 카드매출 옥포 비중과 맞는지 `validation.json` 에 적는다.
6. 재현을 위해 seed를 고정한다. 표준 라이브러리 Python으로 `tools/build_personas.py` 를 만들고 `python3 -I` 로 실행한다.
