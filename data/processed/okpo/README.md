# 옥포 구역 페르소나 입력 데이터

구현 구역: 「옥포로·성안로 ~ 옥포국제시장 일대」(구 옥포 외국인거리·빛의 거리), 거제시 **옥포1동·옥포2동**.
만드는 스크립트: `python3 -I tools/build_okpo_inputs.py` (원자료 `data/raw/geoje/` → 이 폴더, 모두 UTF-8 BOM CSV)

## 쓸 때 주의
- 카드매출 `연령대`에 **'기업'**(법인카드)이 섞여 있다. 개인 페르소나를 만들 때는 빼야 한다.
- 카드매출은 관광지 관련 업종 기준이며, 데이터가 한 시점(2025-02-28, 2개월 집계)뿐이라 계절 차이는 없다.
- `10`·`11`·`13`은 동 단위 자료가 없어 거제시 전체 값이다. 옥포 값처럼 쓰지 않는다.
- 시간대별 도착 분포와 대기 한계는 공공데이터가 없다. 가정값으로 정하고 가정이라고 표시한다.
