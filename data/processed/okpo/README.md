## 쓸 때 주의
- 카드매출(`04~07`) `연령대`에 **'기업'**(법인카드)이 섞여 있다. 개인 페르소나 생성·검증에서는 제외한다.
- 옥포1동 `동 생활인구(시각 평균 인원)`(2026년 1~9월 평균 8,894명)은 **10세 이상·등록외국인 포함** 기준이고, 거제시 월보·소상공인365의 약 2.9만 명은 **하루 다녀간 사람 수(일 단위 순유동)** 에 해당한다(`docs/flow-references.md` 5절).
- `19·20`의 원자료(`2025_국민여행조사_원자료_국내여행.zip`, 328MB)는 `.gitignore` 대상이라 저장소에 넣지 않는다. 원자료가 없는 환경에서 `build_okpo_inputs.py`를 돌리면 이미 커밋된 `19·20` CSV를 그대로 유지한다.
