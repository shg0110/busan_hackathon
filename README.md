# 서비스 소개

<!--
  한두 문장으로: 누가, 무엇을, 어떻게 쓰는 서비스인지.
  대구 드래프톤의 '동성로 창업 리허설'(3D 상권 + 가상 방문자 + 가게 실험)과 같은 결을 거제 옥포에 적용했다.
  서비스 이름은 아직 정하지 않았다. 정해지면 제목과 이 칸에 넣는다.
-->

동남권(부산·울산·경남)에서 상가 공실률이 가장 높은 **경남 거제 옥포 상권**을 3D 지도로 옮긴 웹 화면입니다.
빈 점포에 가게를 열려는 사람이 가게를 열기 전에
**"이 빈 자리에 이런 가게를 열면 손님이 올까?"**를
가상 손님(조선소 통근자·외국인 근로자·주민·주말 관광객)으로 먼저 실험해 볼 수 있게 만드는 것이 목표입니다.

> 가상 손님은 실제 사람이 아닌 계산용 인물입니다.
> 결과는 실제 매출 예측이 아니라 **조건끼리 비교하는 용도**입니다.

## 해결하려는 문제

<!-- 대상(누가) · 상황 · 불편 · 핵심 근거(수치+출처) 순서로 쓴다. 근거는 docs/ 조사 문서에서 가져온다. -->

**누가:** 거제 옥포의 빈 점포에 가게를 열려는 예비 창업자, 빈 점포를 채우려는 건물주와 거제시.

**상황: 옥포는 동남권에서 빈 상가가 가장 많은 상권입니다.**

| 항목 | 값 | 출처 |
|---|---:|---|
| 옥포 상가 공실률(건물 전체, 일반 상가) | **32.77%** | 한국부동산원 R-ONE 상업용부동산 임대동향조사, 2026년 3분기 |
| 옥포 큰 건물(중대형) 공실률 | **37.99%** | 같음 |
| 동남권 46개 상권 중 순위 | **1위** | 같음(`docs/dongnam-ranking.md`) |
| 2년 전 옥포 공실률 | 25.60% | 같음, 2024년 3분기 |
| 같은 거제시 고현 공실률 | 14.78% | 같음, 2026년 3분기 |
| 경남 평균 공실률 | 16.33% | 같음, 2026년 3분기 |

- 2년 새 25.6% → 32.8%로 올랐고, 경남 평균보다 **16.4%p** 높습니다.
  같은 거제시 고현은 14.8%라서, 공실은 거제 전체가 아니라 **옥포에 몰려 있습니다.**
- 보도가 짚은 원인은 같습니다. **조선소 실적은 살아났는데 옥포 상권은 살아나지 않았습니다.**
  소비 중심이 아주동 등으로 옮겨 갔고, 인구 구조가 외국인 근로자 중심으로 바뀌었습니다.
  (시사저널 2026-02-27, GIB 거제인터넷방송 2026-10-18, 뉴시스 2025-04-22. 링크는 `docs/okpo-evidence.md` 2절)

**불편:**

- **어디가 비었는지 알 수 없습니다.**
  옥포 빈 점포의 주소를 공개한 목록이나 기사는 찾지 못했습니다.
  기사는 "임대문의 딱지"처럼 모습만 전합니다(`docs/okpo-evidence.md` 4절).
- **열어 보기 전에는 손님이 올지 알 수 없습니다.**
  누가 언제 이 거리를 지나가는지(조선소 출퇴근, 외국인 근로자, 주말 관광객)를 가게 자리마다 따져 볼 도구가 없습니다.
- **빈 점포를 채우는 지원은 옥포가 아니라 고현에 들어갑니다.**
  - 고현은 중소벤처기업부 상권활성화 사업 80억 원(2025~2029)으로 빈 점포를 공용 공간(인큐베이팅랩)으로 바꾸고 있습니다(거제인터넷신문 2026-11-23).
  - 옥포는 도시재생 뉴딜(2026년 예산 70억 원)과 거리 전선 지중화(15억 원)가 있지만,
    **빈 점포를 직접 채우는 사업은 확인되지 않았습니다**(브릿지경제 2025-11-22).
  - 거제시 상권활성화 예산은 2026년 25억 원에서 2027년 21억 원으로 줄었습니다(새거제신문 2026-11-20).

## 핵심 기능

<!--
  시연 화면에서 실제로 보여 줄 수 있는 기능만 적는다.
  '만드는 중'인 기능은 화면에서 확인되면 '됨'으로 바꾼다. 확인 전에는 '됨'으로 적지 않는다.
-->

| 기능 | 상태 |
|---|---|
| 1. 옥포 상권 3D 지도 + 공실률 카드 | 됨 |
| 2. 층마다 빈 상가 층 표시 | 만드는 중 |
| 3. 가상 손님 하루 시뮬레이션 + 빈 점포에 가게 열어 보기 | 만드는 중 |

- **기능 1. 옥포 상권 3D 지도 + 공실률 카드**
  - 건물 2,165채(OpenStreetMap 2,018채, 그중 층수 확인 1,992채 + Overture Maps 147채, 층수 추정)를 실제 위치·층수로 세웠습니다.
    바다·녹지·도로·지명도 올렸습니다.
  - 건물을 누르면 정보가 나옵니다. 층수를 추정한 건물은 따로 켜고 끌 수 있습니다.
  - 요약 카드에 옥포 공실률(32.8%, 동남권 1위)과 2년 추이를 같은 거제 고현·경남 평균과 나란히 그립니다.
    숫자는 `tools/web_stats.py`가 R-ONE 원자료에서 직접 만듭니다.
- **기능 2. 층마다 빈 상가 층 표시** (만드는 중)
  - 건축물대장 층별개요로 층마다 용도(근린생활시설 등)를 알아내고,
    소상공인 상가(상권)정보에서 그 층에 영업 중인 가게가 있는지 대조합니다.
  - 상가 용도인데 등록된 가게가 없는 층을 3D 안에서 바로 보이게 합니다.
    공실률을 1층만이 아니라 **건물 전체 기준**으로 보는 것과 같은 이유입니다(3층 건물에 2층만 비어도 공실).
- **기능 3. 가상 손님 하루 시뮬레이션 + 빈 점포에 가게 열어 보기** (만드는 중)
  - 조선소 통근자·외국인 근로자·주민·주말 관광객이 하루 동안 옥포를 오가며 가게를 고릅니다.
  - 빈 점포를 골라 업종·가격을 정하고 가게를 열면, 열기 전과 뒤에 손님 수를 비교합니다.
  - 빈 점포 후보는 행정안전부 인허가 자료의 폐업 기록과 지금 영업 중인 가게를 대조해 추정합니다.

## 기술 스택

<!--
  각 항목에 "무엇을 · 왜 쓰는지"를 한 줄로 적는다. 실제로 쓰지 않게 되면 줄을 지운다.
  여기 적은 것은 2026-11-27 저장소에서 실제로 쓰고 있는 것만이다(쓸 계획만 있는 것은 적지 않는다).
-->

- **프론트엔드: HTML + JavaScript + three.js r147**
  <!--
    three.js: 웹 브라우저에서 3D를 그리는 라이브러리. 건물 2천여 채를 한 화면에 그리려고 쓴다.
    r147 은 ES 모듈이 아닌 일반 <script> 로 불러 쓸 수 있는 판이라, 서버 없이 file:// 로 열어도 돌아간다.
    라이브러리 파일은 web/vendor/ 에 넣어 두어 인터넷이 끊겨도 화면이 뜬다(시연장 와이파이 문제 대비).
    OrbitControls(끌어서 돌리기·확대), BufferGeometryUtils(건물을 한 덩어리로 합쳐 빨리 그리기)도 같은 폴더에 있다.
  -->
  - `web/index.html`을 크롬으로 열면 바로 뜹니다. 빌드 과정, 서버, 설치가 없습니다.
  - 3D 그리기는 three.js, 화면 조작은 OrbitControls, 건물 합치기는 BufferGeometryUtils를 씁니다(`web/vendor/`).
  - 지도·통계 자료는 `web/data/*.js`에 미리 만들어 넣어, 화면이 외부 API를 부르지 않습니다.
- **백엔드: 없음(정적 파일) + Python 3 데이터 가공 스크립트**
  <!--
    서버를 두지 않는다. 공공데이터를 tools/ 의 Python 스크립트로 미리 내려받고 걸러서 web/data/ 에 JS 파일로 넣는다.
    이렇게 하면 시연할 때 API 키·호출 한도·서버 장애를 신경 쓰지 않아도 된다.
    대부분 표준 라이브러리(urllib, json, csv)만 쓴다.
    지도 겹침 계산(shapely)과 Overture 대용량 파일 읽기(duckdb)만 가상환경 ~/.venvs/busan-geo 에서 돌린다.
    실행은 python3 -I tools/<스크립트>.py 로 한다(-I: 현재 폴더의 같은 이름 파일을 잘못 불러오지 않게).
  -->
  - `tools/`의 Python 3 스크립트가 공공데이터를 내려받고 걸러서 `data/processed/`와 `web/data/`에 넣습니다.
  - 표준 라이브러리 위주이고, 도형 계산은 shapely, Overture 건물 파일 읽기는 duckdb를 씁니다.
- **AI / 기타**
  <!--
    AI를 어디에 왜 쓰는지는 심사 항목(AI 활용 적합성)과 바로 이어지므로, 'AI 없이 하면 어떻게 되는지'와 같이 적는다.
    화면 안에서 외부 유료 LLM(챗GPT·Claude API 등)은 부르지 않는다. 키·비용·인터넷 없이 시연장에서 돌아가게 하려는 것이다.
    가상 손님 시뮬레이션은 규칙 기반 행위자(agent) 모델이다. 사람마다 도착 시각·예산·업종 선호가 있고, 그에 따라 가게를 고른다.
    이것을 'AI'라고 부를지는 발표 때 정확히 설명한다(LLM이라고 말하지 않는다).
  -->
  - **가상 손님 시뮬레이션** (만드는 중): 도착 시각·예산·선호 업종·대기 한계를 가진 가상 인물이 옥포를 돌며 가게를 고릅니다.
    AI 없이 하면 "이 자리에 열면 될까"를 감과 발품으로만 판단해야 합니다.
  - **데이터 출처**
    <!-- 키가 필요한 것은 .env 에 넣는다(.env.example 참고). 받는 법은 docs/okpo-evidence.md 5절. -->
    - 한국부동산원 R-ONE 상업용부동산 임대동향조사(Open API): 상권별 공실률(일반·중대형·소규모·집합), 2024년 3분기~2026년 3분기
    - OpenStreetMap: 건물 모양·층수, 도로, 바다·녹지, 지명, 버스 정류장
    - Overture Maps: OSM에 없는 건물 보충
    - 국토교통부 GIS건물통합정보(브이월드, 경남): 건물 정보 대조
    - 국토교통부 건축HUB 건축물대장 층별개요(공공데이터포털 API): 층마다 용도·면적
    - 소상공인시장진흥공단 상가(상권)정보(경남, 2026년 9월): 지금 영업 중인 가게 위치·업종·층
    - 행정안전부 지방행정 인허가(일반·휴게음식점, 공공데이터포털 API): 폐업 기록 → 빈 점포 후보 추정
  - **점검: playwright** (`tools/web_check.js`)

    - 폰·노트북·넓은 화면 세 크기에서 콘솔 오류, 패널 겹침·글자 잘림, 버튼 동작, 프레임 수(fps)를 자동으로 잽니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `data/raw/` | 내려받은 원자료 그대로(손대지 않음). 큰 파일은 올리지 말고 받는 방법을 `docs/okpo-evidence.md` 5절에 적는다 |
| `data/processed/` | 스크립트로 가공한 결과 |
| `tools/` | 자료 받기·가공 스크립트, 화면 자동 점검 |
| `web/` | 시연 화면(`web/index.html`) |
| `docs/` | 조사 문서(근거·출처). 옥포 근거는 `okpo-evidence.md`, 동남권 순위는 `dongnam-ranking.md` |

## 함께 작업하는 규칙

- `main` 에 바로 올리지 않는다. `이름/작업` 브랜치(예: `junhyeok/vacancy-map`)에서 작업하고 PR로 합친다.
- API 키는 절대 커밋하지 않는다. `.env.example` 을 복사해 `.env` 로 만들어 쓴다(`.env` 는 `.gitignore` 에 있음).
- 근거 수치는 확인한 것·추정·미확인을 구분해 적는다. 가상 인물 결과를 실제 근거처럼 쓰지 않는다.
